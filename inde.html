Главное меню

Всё, что делает WERON

1
Установить версию Python
Ставит нужную версию Python прямо в Termux.
2
Установить полезные модули
Подтягивает pip-пакеты, а нативные — через pkg, с автоматическими фолбэками.
3
Полезные утилиты
Набор системных инструментов на каждый день.
4
Обфускация .py-скрипта
Скрывает исходный код от чтения глазами (не шифрование).
5
Настоящее AES-шифрование файла
Пароль → PBKDF2 → ключ Fernet. Без пароля файл не восстановить.
6
Модули софта
Показывает, что установлено, а что ещё нужно — обязательное и рекомендуемое.
Установка

Запуск в три строки

pkg install python -y wget https://raw.githubusercontent.com/zenizenit020-cmd/Weron/main/termux_toolkit-1.py python termux_toolkit-1.py
